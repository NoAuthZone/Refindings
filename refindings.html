Settings

Review interval. An accepted risk gets a review date this many days after it is accepted; when the date has passed it is flagged "review due" and no longer suppressed by the FalconEYE baseline. 0 = no review date.

Fix deadlines (SLA). Open or confirmed findings older than this (days since first seen) are flagged "SLA overdue" and listed in the report. 0 = no deadline.

days

Editor link. With the local path to the code base, file references become links that open the file at the flagged line in your editor. The setting is stored in the project file.

Rules

Rules set a status for all matching findings that have no individual rating, including future scans. Patterns refer to the relative path: * = any characters except /, ** = any subfolders. Example: external/** as accepted risk.

Loaded scans

Raw data is not kept, only the finding history. Removing a scan deletes its sightings; findings without any other sighting disappear together with their rating.
